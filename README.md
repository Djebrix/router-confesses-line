# The Router Confesses

One line in which a home Wi-Fi router excuses itself for dying at the
climax of a movie — a make.fun bounty entry by [@Djebrix](https://make.fun).

## The line

> I dropped you at the climax because I already knew the twist — and unlike your group chat, I can keep a secret.

## How it works

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`.
No network, no randomness, no timestamps — every run produces the
exact same bytes.
